# Section 05:自己做還是買現成的

## 段落定位

**存在理由**:前四段講完「怎麼做」,聽眾席上的創辦人心裡會浮出一個很實際的反問:
「那我為什麼不直接買現成的?」不回答,他們帶不走任何可以行動的東西;
回答得太細,又會變成產品評比。這段只給**一條線**,並順勢說明剛剛學到的不是一個文案技巧、
是一套流程 —— 這是把主軸從「這個案例」提升到「你的案例」的關鍵一步。

**討論方向**:對比取捨。判準優先於清單,一句話帶得走。

## 內容要點

1. **一條分界線**(新知,全場最想被記住的一句話):
   內部知識問答(HR 規章、IT 支援、合約查詢)—— **買**。這種需求每家公司都長一樣,
   企業級方案兩週上線,自己做三個月而且做得比較差。
   商品文案這條 pipeline —— **自己做**。它是你的差異化,而且必須串進你的 PIM、上架流程、品牌規範。
   > **這個 AI 功能會不會出現在你的產品定價頁上?會 → 自己做。不會 → 買現成的。**
2. **方法論可遷移**(新知):同一套方法反過來用。
   場景 A:結構化資料 → 非結構化文字(生成商品文案);場景 B:非結構化文字 → 結構化資料(評論洞察進 BigQuery)。
   一樣要 schema、一樣要評測、一樣要算成本。
   容易被忽略的設計:**要把「商品不好」和「服務不好」分開** —— 客人抱怨物流慢不是商品問題,
   混在一起統計,採購會砍掉一個其實賣得很好的品項。
   所以你剛剛學的**不是一個文案技巧,是一套流程**。

**紀律**:**不主動點名任何產品**。QA 被問到具體方案再談(對照組 `talk/script.md` 附錄 A)。
