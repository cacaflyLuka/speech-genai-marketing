# Section 04:三層評測與實測結果

## 段落定位

**存在理由**:這是全場重心,主張「你怎麼知道它有沒有變好」的正面回答。
前一段造出了四個版本,這一段給出**判斷它們的方法與證據**。
拿掉這段,整場就退化成一篇 prompt 教學 —— 而 prompt 教學網路上有一千篇。

**討論方向**:原理拆解 + 實證。先立三層結構(便宜到貴,順序很重要),逐層說明各自擋什麼、
花多少錢、什麼時候不可靠,最後用 50 筆實測收尾 —— 包含**誠實說出哪些差距不能宣稱**。

## 內容要點

1. **三層評測**(新知):規則(免費/毫秒/長度格式禁詞必含規格)→ LLM judge(有成本/秒/語調賣點覆蓋)
   → 人工(最貴/天/前兩層有分歧的)。**多數團隊一上來就做 LLM judge,又貴又不穩,然後放棄。**
   先建規則層:免費、確定性、可以進 CI。
2. **法規禁詞 = 全場最重要的一頁**(新知,對創辦人衝擊最大):
   食安法 §28 II 宣稱醫療效能罰 **NT$60 萬–500 萬**;§28 I 不實誇張 4 萬–400 萬;
   化粧品衛管法 §10 虛偽誇大 4 萬–20 萬。
   **AI 不知道它違法了** —— 它照著網路上幾百萬則違規廣告學來的,覺得這樣寫很正常。
3. **80 → 98 → 100 這條線**(新知,全場最有力的實證):
   v0 禁詞 0 命中 80%(五筆一筆踩雷)、v1 98%、v2 100%。
   五分之一踩雷,十萬 SKU 就是兩萬個;prompt 約束降到 2%,**但 2% 不是 0%**,還是兩千個。
   而且 98% 這數字本身是量出來才知道的 —— **沒有評測,你連自己有沒有 2% 的問題都不知道。**
   結論:prompt 只能降低機率,規則層才能給保證,而且它免費。
4. **規則層能給方向,不只是擋**(新知):`✗ 護眼 → ✓ 陪伴長時間用眼的日常` 等替代寫法。
   ⚠️ **今天 demo 就到「印出來給人看」為止**;自動回灌重寫是上線後才做的事,用虛線框標。
   `rules.suggest_fix()` 目前只回傳 `{禁詞: 替代寫法}`,notebook 拿到就 print,沒有任何東西被送回模型。
5. **LLM judge:不要用 1–5 分**(新知,方法論轉折):Likert 的五個問題(擠在 3–4 分 / 不可重現 /
   換評審模型整組平移 / verbosity bias / 「3.8 分」無法行動)。改成二元判準:
   把模糊的大問題拆成一組具體的 yes/no 小問題。GEAP 的 Gen AI Evaluation Service 把這種判準形容成
   **「像單元測試」**。關鍵細節:**rubric 從商品資料生成,不是看著文案出題**,四版考同一份考卷。
6. **judge 的偏誤與緩解**(新知,建立可信度):self-preference → 評審與生成刻意用不同模型;
   verbosity → 二元判準 +「不因長度加分」明令;position → 單篇對照不做成對;
   criteria drift → rubric 每商品生成一次跨版本共用。
   **一個會告訴你它什麼時候不準的工具,比一個宣稱永遠準的工具有用。**
7. **實測結論:每一版做對一件事**(新知,誠信時刻):
   四版 × 四個指標的對比表,加配對比較的 95% CI ——
   只有 v1→v2 統計成立(+8.86pp);v1−v0(+4.86pp)與 v3−v2(−1.43pp)的區間都跨過 0。
   **v3 沒有讓文案變好,是讓文案變得可用**(可機器讀取 0% → 100%)。

## 先備知識

- 聽眾:需要 section-03 造出的 v0–v3 四個版本(`depends-on: [section-03]`),
  否則表格的欄位沒有意義。95% 信賴區間對非技術聽眾用白話講:「這個區間跨過零,代表我分不出差別」。
- 講者:**數字必須背準**,而且措辭要保守 —— 50 筆 × 7 條 = 350 次檢查、單次翻轉 0.29pp
  那是**解析度不是顯著性**;配對比較的 CI 寬達 ±5pp,差一個數量級。
  「分不出差別」**不等於**「一樣好」。法規部分只講到「這是規則層要擋的東西」為止,
  不延伸成法規講座、不給法律意見;被追問就說「商用前要讓法務或法規顧問審過,我這份是簡化示範版」。

## 備註要點

- **銜接**:接第三段的「哪個比較好」→ 這一段就是回答方法。
- 第 2、3 頁**不要講太快**,80 → 98 → 100 這條線同時證明三件事:AI 真的會違規、prompt 有用但不夠、規則層是必要的。
- 第 4 頁:虛線 = 上線才需要,與 diagram-06-1 同一個約定。**不要講成「它會自動改好」。**
  工程師若問「為什麼不乾脆自動回灌」→ 可以而且應該,但三件事不能省:改完要重檢、不能字串取代
  (要讓模型帶著方向重寫,不是 sed)、要設上限(每一輪都是真的錢,接得到第六段的成本)。
- 第 7 頁是**全場最重要的誠信時刻**。主動說「這兩個差距我不能宣稱」,比任何漂亮數字都更能建立信任;
  而且它剛好收在主軸上 —— 你要能同時說出「這裡變好了」跟「這裡我還不知道」。
- 時間警戒:7 分鐘 7 頁,平均一頁 60 秒,但第 2–3 頁要 2 分鐘。壓縮先砍第 6 頁(偏誤表)。
- **交棒**:既然評測可以工程化,那什麼該自己做、什麼該買?
