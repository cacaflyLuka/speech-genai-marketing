## 段落定位

**存在理由**:section-03 給了尺,這段給量出來的結果 —— 沒有這一頁,聽眾不知道那三層尺
到底判出了什麼,section-05 的 demo 也就沒有可以對照的數字。

**與主軸的掛勾**:核心訊息說「你怎麼知道它有沒有變好」,這段是那個「知道」的具體樣子。

**討論方向**:結果呈現 —— 一張表講完,統計方法完全不上投影片。

## 內容要點

1. **四版的評測結果**(新知,本段唯一的頁面內容)。rubric 通過率
   v0 **73.1%** → v1 **78.0%** → v2 **86.8%** → v3 **85.4%**;
   可機器讀取 0% / 0% / 0% → **100%**。
2. **誤差用口述帶過**(講者口白,不上投影片)。這些百分比都帶著誤差,但誤差不影響
   「哪一版比較好」的判斷 —— v2 那一版的改善站得住,v1 與 v3 的差距還在雜訊裡。
   被追問時再展開方法(配對比較 + bootstrap 95% CI),不主動講。
3. **v3 的正確說法**(回收 section-02 的伏筆)。v3 沒有讓文案變好,是讓文案**變得可用** ——
   可機器讀取 0% → 100%,這一項不需要統計,因為它不是程度問題,是有無問題。

**本次調整刪除的點(2026-08-19,使用者決定)**:原本 5 頁 6 分鐘的「數字也會騙人」整段
—— 誤差棒圖(diagram-04-1,已刪除)、「解析度不等於顯著性」技術頁、
「分不出差別不等於一樣好」頁、以及該段的轉場頁。
**理由**:台下一半是非技術背景的創辦人／PM,用四頁投影片講統計顯著性會流失大量聽眾;
誤差這件事用一句口述交代即可,結論本身不受影響。
配對比較的區間數字保留在講者手上(見備註),被問到才展開。
